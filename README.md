## ▶️ Getting Started

### Prerequisites

* .NET SDK installed
* Visual Studio or compatible IDE

### Run the App

```bash
dotnet build
dotnet run
```

Or in Visual Studio:

* Open the `.sln` file
* Press `F5` to run

---

## ⚠️ Limitations

* Assumes valid numeric input
* No input validation implemented
